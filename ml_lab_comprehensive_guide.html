Experiment 01

Automated Machine Learning Workflow & Generalized Exploratory Data Analysis

Workflow
📌 What the Experiment Is & The Problem Solved

In production ML, datasets arrive in heterogeneous modalities (continuous, categorical, skewed, missing values). Experiment 1 builds an Automated Generalized Exploratory Data Analysis (EDA) pipeline that autonomously ingests any tabular dataset (Iris, Loan Amount, Pima Diabetes, Spambase, MNIST Digits), detects the problem type (classification vs. regression), generates a consolidated 12-panel visualization, and selects optimal feature-selection techniques.

💡 Key Decisions Made: How & Why We Did It
  • Automated Problem Detection: If target cardinality is low ($\le 20$) or discrete/string, it is flagged as Classification. If continuous floating-point with high unique ratio, it is flagged as Regression.
  • Median Imputation for Skewed Features: Clinical indicators (e.g., Insulin, SkinThickness in Diabetes with zero-artifacts) are imputed using the median, which is resistant to extreme outliers.
  • ANOVA F-Score Feature Ranking: We used SelectKBest(score_func=f_classif) because it computes the ratio of between-class variance to within-class variance: $$F = \frac{\text{MS}_{\text{between}}}{\text{MS}_{\text{within}}}$$
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why NOT drop rows with missing values (dropna())? In medical datasets like Pima Diabetes, dropping records with zero insulin drops nearly 40% of the entire dataset. This introduces severe survival bias and cripples statistical power.
  • Why NOT Min-Max Normalization $[0, 1]$ for Gaussian-like features? Min-Max scaling is extremely fragile to outliers. A single extreme outlier will compress 99% of normal patient readings into a microscopic band ($[0.0, 0.05]$). StandardScaler ($\mu=0, \sigma=1$) was chosen because it preserves variance and outlier leverage.
  • Why NOT One-Hot Encode high-cardinality nominals? Creating 100+ sparse dummy columns triggers the curse of dimensionality, causing tree algorithms to dilute split decisions.
💻 Key Code Snippet: Automated Pipeline Decision Logic
def detect_problem_type(df, target_col):
    target = df[target_col]
    # If target is string or unique count is small relative to rows, it is Classification
    if target.dtype == 'object' or target.nunique() <= min(20, len(df) * 0.05):
        return "Classification", target.nunique()
    return "Regression", target.nunique()

# Strict preprocessing pipeline: prevents data leakage
num_pipeline = Pipeline([
    ('imputer', SimpleImputer(strategy='median')),
    ('scaler', StandardScaler())
])
🎯 Viva & Demo Defense: Questions You Might Face
Q: "Why do we say zero values in Pima Indians Diabetes are missing values?"
Answer: Biological impossibility. Human blood pressure, glucose, BMI, and skin thickness cannot be zero in living individuals. Zeroes in this dataset represent missing measurements encoded as 0. Imputing with median restores physiological validity.
Q: "What is the difference between ANOVA and Chi-Square for feature selection?"
Answer: ANOVA ($F$-test) is used when input features are continuous/numerical and target is categorical. Chi-Square ($\chi^2$) is strictly for categorical input features against categorical targets.
Experiment 02

Email Spam Classification using Naïve Bayes & K-Nearest Neighbors (KNN)

Bayes vs KNN
📌 What the Experiment Is & The Problem Solved

Classifying emails as Spam or Ham on the 57-feature Spambase dataset. The experiment contrasts a generative probabilistic model (Naïve Bayes) against an instance-based non-parametric model (K-Nearest Neighbors), and explores hyperparameter optimization via Grid Search vs. Randomized Search.

💡 Key Decisions Made: How & Why We Did It
  • Bernoulli vs Multinomial vs Gaussian NB: Multinomial and Gaussian NB achieved >87% accuracy. We selected Gaussian with var_smoothing=1e-9 to prevent division-by-zero on zero-variance continuous features.
  • Manhattan ($L_1$) Distance over Euclidean ($L_2$) for KNN: In a 57-dimensional word-frequency space, Euclidean distance suffers from distance concentration. Manhattan distance measures orthogonal token discrepancy more robustly.
  • Odd Values of $k$ ($k=1, 3, 5, 7, 9, 11$): Selected strictly odd $k$ values to mathematically eliminate majority voting ties in binary classification.
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why NOT Bernoulli Naïve Bayes? Bernoulli NB binarizes features ($x_i \in \{0, 1\}$). It completely ignores word frequency! An email containing the word "win" 20 times is treated identically to an email containing it once, losing vital spam intensity signals.
  • Why NOT choose $k=1$ in KNN? $k=1$ achieves 100% training accuracy but memorizes label noise and outliers (extreme variance/overfitting). Optimal performance stabilized at $k=7$ to $11$.
  • Why NOT large $k$ ($k > 30$)? High $k$ leads to high bias: the neighborhood expands so widely that majority class (Ham, 60%) completely swallows the minority class (Spam, 40%).
🎯 Viva & Demo Defense: Questions You Might Face
Q: "Why is Naïve Bayes called 'Naïve'?"
Answer: It makes the mathematically unrealistic assumption that all features are conditionally independent given the class: $P(X_1, \dots, X_d | Y) = \prod_{i=1}^d P(X_i | Y)$. In language, words like 'credit' and 'card' correlate strongly, yet NB still classifies well because classification depends on probability rank, not exact calibration.
Q: "Grid Search vs. Randomized Search: when to use which?"
Answer: Grid Search checks every combination exhaustively ($O(\prod |S_i|)$). Randomized Search samples a fixed budget of random combinations; Bergstra & Bengio (2012) proved Randomized Search finds equally optimal hyperparameters in a fraction of the time, especially when only a subset of hyperparameters truly drive performance.
Experiment 03

Linear Regression & Regularization (Ridge, Lasso, ElasticNet)

Regularization
📌 What the Experiment Is & The Problem Solved

Predicting continuous values while diagnosing multicollinearity and preventing overfitting. The experiment investigates why unregularized Ordinary Least Squares (OLS) fails under collinearity, and how penalty constraints ($L_1$, $L_2$, ElasticNet) constrain the parameter space.

💡 Key Decisions Made: How & Why We Did It
  • Ridge ($L_2$) for Multicollinear Features: Adds quadratic weight penalty $\alpha \sum w_j^2$. Prevents $(X^T X)^{-1}$ singular matrix inversion blowup by adding $\alpha I$ to the diagonal.
  • Lasso ($L_1$) for Sparse Feature Selection: Adds absolute weight penalty $\alpha \sum |w_j|$. Shrinks non-informative coefficients to exactly zero.
  • ElasticNet for Grouping Effect: Combines $L_1$ and $L_2$: $$\mathcal{L} = \text{MSE} + \alpha \rho \sum |w_j| + \frac{\alpha(1-\rho)}{2} \sum w_j^2$$
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why NOT run Ridge or Lasso without standardizing features first? CRITICAL TRAP! Penalties $\sum w_j^2$ and $\sum |w_j|$ penalize all coefficients equally. If feature $X_1$ is income in dollars ($10^5$) and $X_2$ is household size ($10^0$), $w_1$ will naturally be $10^{-5}$ smaller. The regularization will penalize $w_2$ heavily while leaving $w_1$ untouched! Standardization is mathematically mandatory before regularized regression.
  • Why NOT choose Lasso when two features have a correlation > 0.95? Lasso arbitrarily picks one feature at random and zeroes out the other, losing domain interpretability. ElasticNet preserves both.
🎯 Viva & Demo Defense: Questions You Might Face
Q: "Why does Lasso produce exact zeroes while Ridge only shrinks close to zero?"
Answer: Geometry of the constraint region. The $L_1$ ball is a diamond with sharp corners on the coordinate axes. The elliptical loss contours touch the diamond at these axis corners where $w_i = 0$. The $L_2$ ball is a smooth circle/hypersphere, so loss contours touch at non-zero tangent points.
Experiment 04

Support Vector Machines (SVM) Kernel and Hyperparameter Tuning

Max Margin
📌 What the Experiment Is & The Problem Solved

Maximizing the geometric margin between decision boundaries and closest data points (support vectors). The experiment evaluates Linear, Polynomial, and Radial Basis Function (RBF) kernels while systematically tuning the soft-margin penalty $C$ and kernel bandwidth $\gamma$.

💡 Key Decisions Made: How & Why We Did It
  • RBF Kernel for Complex Non-linear Data: Maps data into infinite-dimensional Hilbert space using the Gaussian kernel: $$K(x, x') = \exp(-\gamma \|x - x'\|^2)$$
  • Balancing $C$ (Penalty) & $\gamma$ (Bandwidth):
    • $C$: Controls trade-off between maximizing margin width and minimizing training classification errors.
    • $\gamma$: Determines the radius of influence of each support vector.
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why NOT use an extremely large $C$ ($C=10^6$)? Extreme $C$ turns the model into a hard-margin SVM. It forces zero margin violations on the training set, causing the boundary to bend violently around noisy outliers (severe overfitting).
  • Why NOT use an extremely high $\gamma$ ($\gamma=100$)? High $\gamma$ creates sharp, needle-like Gaussian peaks around individual support vectors. Points outside the immediate radius are classified as default majority class.
  • Why NOT high-degree Polynomial kernels ($d \ge 5$)? High-degree polynomial kernels suffer from numerical overflow, slow convergence in quadratic programming, and extreme boundary fluctuations at the edges of the feature space.
🎯 Viva & Demo Defense: Questions You Might Face
Q: "What are Support Vectors?"
Answer: Support vectors are the critical data points that lie directly on or inside the margin boundaries ($y_i (w^T x_i + b) \le 1$). Moving or removing any other non-support training points will not change the decision boundary at all.
Experiment 05

Decision Tree & Random Forest (Mitigating Overfitting & Bagging)

Trees & Bagging
📌 What the Experiment Is & The Problem Solved

Diagnosing and curing the fundamental weakness of single decision trees: high variance (overfitting). We evaluate the Wisconsin Diagnostic Breast Cancer dataset (569 samples, 30 continuous features) comparing a standalone pruned tree against a 100-tree Random Forest ensemble.

💡 Key Decisions Made: How & Why We Did It
  • Cost-Complexity Pruning via max_depth=5 & min_samples_split=5: Restricts the depth of individual trees to prevent leaves with single training samples.
  • Random Feature Subsampling (max_features='sqrt'): At each split, Random Forest considers only $\sqrt{30} \approx 5$ random features. This de-correlates the trees!
  • Bootstrapping (bootstrap=True): Each tree trains on an independent sample with replacement of size $N$, leaving $\sim 36.8\%$ Out-of-Bag (OOB) samples for validation.
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why NOT leave max_depth=None for a single tree? Without depth limits, a decision tree will split until every single leaf is pure ($100\%$ training accuracy), creating a brittle staircase boundary that overfits training noise.
  • Why NOT set max_features=1.0 (all features) in Random Forest? If all trees can see all features, they will all pick the single most dominant feature (e.g. worst concave points) at the root node. The trees will all be highly correlated, and averaging correlated trees does NOT reduce variance!
🎯 Viva & Demo Defense: Questions You Might Face
Q: "Why does Random Forest reduce variance without increasing bias?"
Answer: The variance of the average of $B$ random variables with pairwise correlation $\rho$ and variance $\sigma^2$ is $\rho \sigma^2 + \frac{1 - \rho}{B}\sigma^2$. As $B \to \infty$, the second term drops to zero. By randomly sampling features, $\rho$ is minimized, drastically lowering overall variance while individual trees remain unbiased.
Experiment 06

Bagging, Boosting, and Stacked Ensemble Models

Ensemble Paradigms
📌 What the Experiment Is & The Problem Solved

A rigorous head-to-head comparison of the three primary ensemble learning paradigms on the Breast Cancer benchmark: Bagging (parallel variance reduction), Boosting (sequential bias reduction via AdaBoost & Gradient Boosting), and Stacking (heterogeneous blending via a meta-learner).

💡 Key Decisions Made: How & Why We Did It
  • AdaBoost Sample Reweighting: Instances misclassified by model $m$ have their sample weights increased: $$w_i^{(m+1)} = w_i^{(m)} \exp(\alpha_m \mathbb{I}(y_i \neq h_m(x_i)))$$
  • Gradient Boosting Pseudo-Residuals: Sequentially fits decision trees to the negative gradient of the loss function (pseudo-residuals).
  • Heterogeneous Stacking: Combines structurally diverse learners (SVC, GaussianNB, DecisionTree) whose error distributions are uncorrelated, using LogisticRegression as the meta-learner.
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why NOT use a complex non-linear model (like deep Neural Net or Random Forest) as the Stacking meta-learner? A complex meta-learner easily overfits the base predictions, memorizing which base model was right on the training set. A simple regularized linear model (Logistic Regression) acts as an optimal convex weight combiner.
  • Why NOT use AdaBoost when datasets have severe label noise? Exponential loss penalizes misclassifications exponentially ($e^x$). If outliers or mislabeled samples exist, AdaBoost obsesses over them and ruins the overall decision boundary. Gradient Boosting or Huber loss is much more robust.
🎯 Viva & Demo Defense: Questions You Might Face
Q: "Explain the fundamental difference between Bagging and Boosting."
Answer: Bagging trains independent base models in parallel on random bootstrap samples to reduce variance. Boosting trains base models sequentially, where each new model focuses on the errors of preceding models to reduce bias.
Experiment 07

Dimensionality Reduction (PCA), Model Evaluation & Multi-Dataset Statistical Testing

PCA & Unit V Stats
📌 What the Experiment Is & The Problem Solved

Investigating the impact of Principal Component Analysis (PCA) on 10 diverse classifiers evaluated under 5-fold cross-validation. To satisfy faculty verbal instructions, the PCA pipeline was evaluated across all 6 classification datasets from Labs 1–7, followed by a mathematically rigorous 3-tier statistical testing suite grounded in Unit_V notes.pdf.

💡 Key Decisions Made: How & Why We Did It
  • 95% Cumulative Variance Cutoff Criterion: Selected the minimal component count $d$ satisfying: $$\frac{\sum_{i=1}^d \lambda_i}{\sum_{j=1}^D \lambda_j} \ge 0.95$$ Compresses Breast Cancer from $30 \to 10$ components (66.7% reduction) while retaining full structural variance.
  • The 3 Apt Statistical Tests (Unit V Notes Alignment):
    • Tier 1: Paired Two-Sample $t$-Test with Shapiro-Wilk Pre-Check: Evaluates if fold differences $\Delta_i = F1_{\text{PCA}, i} - F1_{\text{No-PCA}, i}$ on identical folds are statistically significant.
    • Tier 2: Wilcoxon Signed-Rank Test: Non-parametric paired ranking test across the 10 heterogeneous model families per dataset ($n=10$) and globally ($N=60$).
    • Tier 3: Friedman Test: Non-parametric two-way ANOVA by ranks comparing all 10 algorithms simultaneously across repeated benchmark blocks without Type I error inflation.
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why NOT an Independent $t$-Test? CRITICAL FACULTY TRAP! Handout & Unit V notes (pp. 4, 26) strictly forbid independent $t$-tests because models are evaluated on the exact same validation folds. The samples are matched pairs; assuming independence violates core statistical assumptions.
  • Why NOT 45 Pairwise $t$-Tests ($\binom{10}{2}$)? Running 45 individual tests inflates the family-wise Type I error rate to $1 - (1-0.05)^{45} \approx \mathbf{90\%}$! The Friedman Test solves this by performing an omnibus rank test across all models simultaneously.
  • Why NOT fit PCA before splitting into Cross-Validation Folds? DATA LEAKAGE! If PCA fits on the entire dataset, the eigenvectors learn variance directions from the test folds. PCA must be enclosed inside an isolated Pipeline that fits only on the training fold: Pipeline([StandardScaler(), PCA(), Classifier()]).
  • Why did Decision Trees plummet under PCA (Rank $8.25 \to 9.67$)? Decision Trees make axis-aligned cuts ($x_j \le \theta$) parallel to coordinate axes. PCA rotates features into dense linear combinations of all variables, destroying natural semantic thresholds.
🎯 Viva & Demo Defense: Questions You Might Face
Q: "Why did Breast Cancer compress 66.7% with zero loss, while Iris (4 to 2) degraded?"
Answer: Breast Cancer contains heavy multicollinearity (radius, perimeter, area correlate at $r > 0.98$). 10 PCs eliminate redundancy without loss. Iris has only 4 features that are already concise; dropping 2 discards non-redundant boundary variance.
Q: "Why did Linear Models (Logistic Regression & SVM) gain top ranks under PCA?"
Answer: PCA diagonalizes the covariance matrix, producing mutually orthogonal predictors with zero covariance ($\text{Cov}(PC_i, PC_j) = 0$). This eliminates multicollinear variance inflation, allowing linear hyperplanes to separate classes with maximum stability.
Experiment 08

Unsupervised Clustering on Human Activity Recognition (UCI HAR)

Clustering HAR
📌 What the Experiment Is & The Problem Solved

Unsupervised pattern discovery on 561 continuous inertial features from waist-mounted smartphones (10,299 instances). The experiment implements and evaluates K-Means Clustering (Elbow & Silhouette optimization), DBSCAN (density-based noise isolation), and Hierarchical Agglomerative Clustering (Ward's linkage).

💡 Key Decisions Made: How & Why We Did It
  • Choosing $k=6$ over $k=2$ in K-Means: The Silhouette score peaked at $k=2$ ($0.3815$) because it cleanly isolates dynamic kinetic movement (walking) from static postures (sitting/standing). However, $k=6$ was chosen because the engineering objective is to separate all 6 physical activities defined by domain ground truth.
  • DBSCAN Parameter Tuning ($\epsilon=15.0, minPts=15$): Filtered $34.57\%$ transitional outlier frames (body state transitions) while maintaining dense core clusters.
  • Ward's Linkage for Hierarchical Clustering: Minimizes the within-cluster sum of squared differences ($\Delta \text{ESS}$), producing compact, equal-variance clusters ($\text{CH} = 705.32$).
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why NOT use Single Linkage for Hierarchical Clustering? THE CHAINING TRAP! Single linkage connects clusters based on the minimum distance between any two single points. It builds long, stringy chains that connect noisy points, collapsing 99% of data into one uninformative blob ($\text{CH} = 11.81$ vs Ward's $705.32$).
  • Why NOT use a small $\epsilon$ ($\epsilon=1.0$ or $5.0$) in DBSCAN? CURSE OF DIMENSIONALITY! In 561-dimensional sensor space, Euclidean distances concentrate: the distance between any two random points approaches a constant. With $\epsilon=10.0$, 93.8% of points are classified as noise! Radius must be expanded to $\epsilon=15.0$.
🎯 Viva & Demo Defense: Questions You Might Face
Q: "Explain the difference between Silhouette Score, Davies-Bouldin, and Calinski-Harabasz."
Answer:
  • Silhouette ($[-1, 1]$): Compares within-cluster distance $a(i)$ to nearest-cluster distance $b(i)$. Higher is better.
  • Davies-Bouldin ($[0, \infty)$): Ratio of within-cluster scatter to separation between centroid pairs. Lower is better.
  • Calinski-Harabasz ($[0, \infty)$): Variance ratio criterion of between-cluster dispersion to within-cluster dispersion. Higher is better.
Experiment 09

Perceptron vs. Multilayer Perceptron (A/B Experiment) with Hyperparameter Tuning

PLA vs MLP
📌 What the Experiment Is & The Problem Solved

Demonstrating the historical and mathematical divergence between a linear single-layer threshold model and a deep connectionist neural network. Evaluated on the 62-class English Handwritten Characters dataset (3,410 images resized to $28 \times 28$, 784 pixel features).

💡 Key Decisions Made: How & Why We Did It
  • Single-Layer PLA from Scratch: Implemented Rosenblatt's weight update rule with step activation: $$w_{t+1} = w_t + \eta(y - \hat{y})x$$
  • Tuned MLP Architecture: Input(784) $\to$ Dense(256, ReLU) $\to$ Dense(128, ReLU) $\to$ Softmax(62) trained with Adam ($\eta=0.001$). Achieved **41.35% accuracy** vs PLA's **12.61%**.
  • Adam Optimizer over SGD: Uses exponential moving averages of gradients ($m_t$) and squared gradients ($v_t$) to provide adaptive per-parameter learning rate scaling.
🚫 What We Chose NOT to Do (And Why Not) — The "Why Not" Analysis
  • Why does Single-Layer PLA underperform (12.61%)? Minsky-Papert Perceptron Theorem! A single-layer perceptron converges if and only if the data is linearly separable. Handwritten characters have curved loops, slants, and complex stroke variations across 62 classes that are fundamentally non-linearly separable. PLA has zero hidden layers and cannot learn intermediate geometric representations.
  • Why NOT Sigmoid in MLP hidden layers? VANISHING GRADIENTS! The derivative of Sigmoid $\sigma'(z) = \sigma(z)(1 - \sigma(z))$ has a maximum value of $0.25$. Multiplying derivatives across hidden layers causes backpropagated error gradients to vanish to zero ($0.25^L \to 0$). ReLU ($\sigma'(z) = 1$ for $z>0$) keeps gradients active.
  • Why NOT 10 hidden layers? On 3,410 total images (only 55 images per class), a 10-layer network has millions of parameters. It quickly memorizes the training data, leading to severe overfitting.
🎯 Viva & Demo Defense: Questions You Might Face
Q: "Why does PLA oscillate and never reach zero error on this dataset?"
Answer: On non-separable data, Rosenblatt's perceptron cycling theorem proves the weight vector will bounce back and forth between conflicting samples indefinitely without converging.

Unit V Statistical Hypothesis Testing Framework

Cheat Sheet
Experimental Situation Appropriate Statistical Test Why It Is Required When It Is Forbidden
Two models on the SAME datasets / CV folds Paired Two-Sample $t$-Test Evaluates matched fold differences $\Delta_i$. Eliminates inter-fold variance. Do NOT use if fold differences fail Shapiro-Wilk normality test ($p < 0.05$).
Two models, non-normal differences Wilcoxon Signed-Rank Test Non-parametric test based on signed ranks of absolute differences $|d_i|$. Do NOT use on independent, non-paired samples.
Three or more models on SAME datasets Friedman Test Non-parametric two-way ANOVA by ranks. Prevents family-wise Type I error inflation. Do NOT use independent One-Way ANOVA (violates block dependence).
Two independent experimental groups Independent $t$-Test Compares independent sample means with pooled variance. Do NOT use when models share the same validation folds or datasets.
