\section{Objective}
To implement, tune, and empirically evaluate artificial neural network architectures on complex optical character glyphs:
\begin{itemize}[noitemsep]
    \item \textbf{Model A:} Single-Layer Perceptron Learning Algorithm (PLA) implemented from scratch with discrete threshold step activation.
    \item \textbf{Model B:} Multilayer Perceptron (MLP) featuring multi-layered non-linear activations (ReLU, Tanh), cross-entropy cost minimization, and backpropagation.
\end{itemize}
Systematic hyperparameter exploration is conducted across layer depth, optimizers (SGD vs. Adam), learning rates, and epochs on the 62-class English Handwritten Characters benchmark.

\section{Problem Statement}
Handwritten character recognition requires identifying 62 highly varied alphanumeric glyphs (0--9, A--Z, a--z). Pixel-level feature spaces exhibit extreme intra-class variability and non-linear stroke boundaries. The problem is to evaluate whether a single linear hyperplane per class (PLA) can discriminate complex glyph variations, and to demonstrate how multi-layer representational abstraction in an MLP circumvents the linear separability constraint.

\section{Data Preprocessing}
Each character image is preprocessed through:
\begin{enumerate}[noitemsep]
    \item \textbf{Grayscale Conversion \& Resizing:} Standardized to $28 \times 28$ matrix format.
    \item \textbf{Pixel Normalization:} Scaled into floating-point range $[0.0, 1.0]$:
    $$x_{\text{norm}} = \frac{x}{255.0}$$
    \item \textbf{Vector Flattening:} Unrolled into a 784-dimensional feature vector $\mathbf{x} \in \mathbb{R}^{784}$.
    \item \textbf{Label Encoding:} Alphanumeric character symbols mapped to integers $\{0, 1, \dots, 61\}$.
\end{enumerate}

\section{Machine Learning Algorithm}
\subsection{Single-Layer Perceptron (PLA)}
A linear decision classifier mapping an input feature vector $\mathbf{x} \in \mathbb{R}^{784}$ through Rosenblatt's step activation:
$$\hat{y}_c = \text{step}(\mathbf{w}_c^T \mathbf{x} + b_c) = \begin{cases} 1 & \text{if } \mathbf{w}_c^T \mathbf{x} + b_c \ge 0 \\ 0 & \text{otherwise} \end{cases}$$
Weights and biases update iteratively:
$$\mathbf{w}_{c}^{(t+1)} = \mathbf{w}_c^{(t)} + \eta (y_c - \hat{y}_c) \mathbf{x}, \quad b_c^{(t+1)} = b_c^{(t)} + \eta (y_c - \hat{y}_c)$$
\textbf{Advantages:} Minimal memory footprint, fast execution ($O(n \cdot d)$). \textbf{Limitations:} Cannot converge on non-linearly separable distributions (Minsky-Papert theorem); zero hidden representations.

\subsection{Multilayer Perceptron (MLP)}
A feedforward neural network comprising an input layer ($784$ units), non-linear hidden layers (ReLU: $\sigma(z) = \max(0, z)$), and an output layer ($62$ units with Softmax):
$$P(y=c|\mathbf{x}) = \frac{\exp(z_c)}{\sum_{j=1}^{62} \exp(z_j)}$$
Trained via backpropagation by minimizing cross-entropy loss:
$$\mathcal{L}(\mathbf{\Theta}) = -\frac{1}{N} \sum_{i=1}^N \sum_{c=1}^C y_{i,c} \log \hat{y}_{i,c}$$
\textbf{Advantages:} Universal function approximator capable of learning hierarchical non-linear stroke representations. \textbf{Limitations:} Computationally intensive, prone to overfitting on limited training instances without regularization.

\section{Discussion}
\subsection{Answers to Faculty Observation Questions}
\begin{enumerate}
    \item \textbf{Why does PLA underperform compared to MLP?} \\
    PLA is constrained to linear decision boundaries in 784-dimensional space. Alphanumeric characters feature rotation, slant, and loop variances that create non-linearly separable class topologies across 62 categories. PLA cannot extract intermediate spatial representations, causing persistent oscillation. The MLP utilizes hidden layers with ReLU activations to construct hierarchical non-linear feature maps where glyphs become separable.
    
    \item \textbf{Which hyperparameters had the most impact on MLP performance?} \\
    Hidden layer architecture (network depth and capacity) and optimizer selection had the highest impact. Single shallow layers (64 units) yielded only 1.47\% accuracy due to severe underfitting, whereas multi-layer configurations ((256, 128)) increased accuracy to 34.80\% by providing adequate representational capacity for 62 classes.
    
    \item \textbf{Did optimizer choice (SGD vs. Adam) affect convergence?} \\
    Yes. Adam outperformed standard SGD by over 11.9\% validation accuracy (29.85\% vs. 17.95\%). Adam's per-parameter adaptive learning rates and momentum prevent gradients from vanishing across deep layers and accelerate traversal across sparse pixel saddle points.
    
    \item \textbf{Did adding more hidden layers always improve results? Why or why not?} \\
    Adding a second hidden layer significantly improved classification from single-layer underfitting. However, scaling beyond three hidden layers without regularization led to diminishing returns and risk of overfitting given the limited training sample size (55 samples per class).
    
    \item \textbf{Did MLP show overfitting? How could it be mitigated?} \\
    A modest generalization gap between training loss (0.4) and validation accuracy (41.35\%) was observed. Overfitting can be mitigated using $L_2$ weight penalty (weight decay), Dropout layers (rate = 0.2--0.3), Early Stopping, and affine data augmentation (shear, slight rotation).
\end{enumerate}

\section{Conclusion}
Experiment 9 experimentally demonstrated the structural limitations of single-layer linear threshold networks and the power of multi-layer connectionist models. The Single-Layer PLA plateaued at 12.61\% accuracy due to linear non-separability, whereas the Tuned Multilayer Perceptron achieved 41.35\% multi-class accuracy on the 62-class benchmark.
