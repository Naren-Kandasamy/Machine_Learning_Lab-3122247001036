\section{Objective}
To implement Logistic Regression and Support Vector Machines (SVM) for binary classification on the Kaggle Spambase dataset. The experiment compares SVM performance across different kernels (Linear, Polynomial, RBF, Sigmoid) and performs hyperparameter tuning using RandomizedSearchCV to optimize both models.

\section{Problem Statement}
The objective is to accurately classify an email as either "Spam" ($1$) or "Ham" ($0$). The input is a robust text-frequency dataset of 57 continuous numerical features representing word and character frequencies. The goal is to maximize classification metrics (Accuracy, Precision, Recall, F1-Score) while balancing training times by applying margin-based and probabilistic linear classifiers.

\section{Exploratory Data Analysis}
EDA confirmed that there is a slight class imbalance (more ham than spam emails), which necessitates the evaluation of F1-Score in addition to strict Accuracy. Features primarily represent float frequencies, requiring uniform scaling so that margin-based algorithms like SVM treat spatial distances fairly.

\section{Data Preprocessing}
\begin{itemize}
\item \textbf{Feature Scaling:} Standardized all features using \texttt{StandardScaler} to achieve zero mean and unit variance. This is extremely critical for SVMs, as they are highly sensitive to unscaled distances, and beneficial for Logistic Regression convergence.
\item \textbf{Sparsity Management:} Because this is NLP-derived tabular data, traditional missing value imputation was omitted as zero implies the true absence of a word.
\item \textbf{Train-test split:} The dataset was split into Training, Validation, and Testing sets using a stratified approach.
\end{itemize}

\section{Machine Learning Algorithm}

\textbf{1. Logistic Regression:}
\begin{itemize}
\item \textbf{Working principle:} Models the probability of the default class using a logistic (sigmoid) function.
\item \textbf{Mathematical formulation:} $P(Y=1|X) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 X)}}$
\item \textbf{Advantages:} Highly interpretable, provides probability outputs, scales well to large datasets.
\end{itemize}

\textbf{2. Support Vector Machine (SVM):}
\begin{itemize}
\item \textbf{Working principle:} Finds the optimal hyperplane that maximizes the margin between the two classes.
\item \textbf{Mathematical formulation:} $\min \frac{1}{2} ||w||^2 + C \sum \xi_i$ subject to $y_i(w \cdot x_i + b) \ge 1 - \xi_i$.
\item \textbf{Kernels:} Uses the kernel trick to project data into higher dimensions if it is not linearly separable.
\end{itemize}

\section{Discussion}
The experiment showed that for the Spambase dataset, the Linear Kernel outperformed non-linear kernels (like Poly and Sigmoid) in accuracy (0.9276 vs 0.8437). This suggests that text-frequency features are generally linearly separable in high-dimensional space. While both Logistic Regression and SVM achieved very similar accuracies post-tuning ($~92.5\%$), Logistic Regression trained significantly faster ($0.0197s$ vs $0.3215s$). The cross-validation confirmed these results were stable and robust against overfitting.

\section{Conclusion}
The experiment successfully implemented Logistic Regression and SVM classifiers. By comparing various SVM kernels, the superiority of the Linear Kernel for this specific NLP feature-set was observed. Both models proved highly competent for spam classification, with Logistic Regression providing the advantage of speed and probability outputs, while SVM provided slightly better strict margin generalization (higher cross-validation F1-score).
