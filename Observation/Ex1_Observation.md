# Experiment 1
**Working with Python packages - Numpy, Scipy, Scikit-Learn, Matplotlib**

**Aim:**
To build a generalised Exploratory Data Analysis (EDA) that handles various datasets, find the machine learning problem type and perform necessary preprocessing. Also exploring Python packages that are imminent for ML tasks.

**ML Task Table**

| Dataset | Type of ML Task | Feature Selection Technique | Suitable ML Algorithm |
| :--- | :--- | :--- | :--- |
| Iris | Multi-class Classification (Supervised) | ANOVA | KNN |
| Loan Amount Prediction | Binary Classification (Supervised) | ANOVA | Logistic Regression |
| Predicting Diabetes | Binary Classification (Supervised) | ANOVA | Logistic Regression |
| Classification of Email Spam | Binary Classification (Supervised) | ANOVA | Naïve Bayes, Log Reg. |
| Handwritten Char Recognition / MNIST | Multi-class Classification (Supervised) | ANOVA | Neural Networks / SVM |

**Learning Outcomes:**
* Understood how to handle missing data through techniques like mean/median imputation and encode categorical variables / features.
* Learned to split datasets into training, validation and test subsets for model evaluation.
* Learned to visualize data through histograms, box plots, scatter plots etc.
