# Syllabus Content for Machine Learning Courses

This document extracts and compiles the full curriculum details, objectives, unit-wise syllabus breakdown, textbook details, and course mapping criteria for **ICS1502 (Introduction to Machine Learning)** and **ICS1512 (Machine Learning Algorithms Laboratory)** from the Regulations 2023 curriculum.

---

## [ICS1502] Introduction to Machine Learning

### Course Overview
* **Category:** Professional Core (PC)
* **Credits:** 3
* **Periods Per Week:** 3 Lecture (L) | 0 Tutorial (T) | 0 Practical (P) | 0 Experiential Learning (E)
* **Total Instructional Periods:** 45 Hours

### Course Objectives
* To understand machine learning problems.
* To apply various supervised, unsupervised learning algorithms for a given scenario.
* To understand the dimensionality reduction techniques.

### Unit-Wise Syllabus

#### Unit I: Introduction (9 Periods)
* Introduction: Machine learning.
* Examples of Machine Learning Applications.
* Machine Learning Categories: Classification, Regression, Unsupervised learning, Reinforcement learning.
* Preliminaries: Testing machine learning algorithms, Basic statistics, Bias-variance tradeoff.

#### Unit II: Supervised Learning (9 Periods)
* Regression: Linear Regression.
* Classifiers: Support Vector Machine (SVM).
* Probabilistic Learning: Conditional Probability, Naive Bayes Classifier.
* Decision Trees: Decision Tree using ID3, Classification and Regression Trees (CART).
* Ensemble Methods: Bagging, Boosting, Random Forest.

#### Unit III: Neural Networks & Association Rule Mining (9 Periods)
* Biological Foundation: The brain and the neuron.
* Neural networks: Multi-Layer Perceptron (MLP) execution example.
* Algorithmic Mathematics: Deriving forward propagation and backward propagation.
* Association rule mining: Apriori algorithm.

#### Unit IV: Unsupervised Learning & Reinforcement Learning (9 Periods)
* Clustering Algorithms: K-Means clustering.
* Dimensionality Reduction: Principal Component Analysis (PCA).
* Reinforcement Learning Foundations: Markov Decision Process (MDP), Q-learning Algorithm.

#### Unit V: Evaluation of Machine Learning Models (9 Periods)
* Execution Guidelines: Best practices for implementing machine learning algorithms.
* Validation Strategies: K-fold Cross-validation, Bootstrapping.
* Performance Metrics: Measuring classifier performance, Assessing a classification algorithm, and Comparing two classification algorithms.

### Course Outcomes (COs)
Upon successful completion of this course, the student will be able to:
* **CO1:** Explain the basic concepts of machine learning (**K2**).
* **CO2:** Apply supervised algorithms for different classification problems (**K3**).
* **CO3:** Construct neural networks in machine learning (**K3**).
* **CO4:** Apply unsupervised and reinforcement learning techniques to various problems (**K3**).
* **CO5:** Evaluate and compare different machine learning models (**K5**).

## [ICS1512] Machine Learning Algorithms Laboratory

### Course Overview
* **Category:** Professional Core (PC)
* **Credits:** 2
* **Periods Per Week:** 0 Lecture (L) | 0 Tutorial (T) | 4 Practical (P) | 0 Experiential Learning (E)
* **Total Lab Periods:** 60 Hours

### Course Objectives
* To apply supervised machine learning techniques.
* To apply unsupervised machine learning techniques.
* To understand feature selection methods.
* To apply appropriate machine learning strategy for any given problem.

### List of Suggested Experiments
1. **Environment Setup & Tooling:** Working with Python data science packages including NumPy, SciPy, Scikit-learn, and Matplotlib.
2. **Linear Regression Application:** Implementing house/loan amount prediction using regression variables.
3. **Support Vector Machine Application:** Classification of email spam data.
4. **Decision Tree Application:** Building medical diagnosis trees (e.g., Prediction of Diabetes datasets).
5. **Ensemble Modeling:** Deploying Random Forest and AdaBoost ensemble techniques to observe accuracy variance.
6. **Neural Network Application:** Developing a multi-layer neural network for Handwritten Character Recognition.
7. **Unsupervised Clustering:** Applying the K-means clustering algorithm onto sample records (e.g., Iris clustering).
8. **Dimensionality Reduction:** Executing and mapping components utilizing dimensionality reduction strategies on dense datasets.
9. **Capstone Mini-Project:** Evaluating supervised or unsupervised machine learning frameworks against open-ended, real-time targets across specific challenge tracks:
   * (a) Text Processing
   * (b) Image Processing
   * (c) IoT Systems

### Course Outcomes (COs)
Upon successful completion of this lab course, the student will be able to:
* **CO1:** Apply supervised and unsupervised learning techniques for various problems (**K3**).
* **CO2:** Apply ensemble techniques to solve problems and demonstrate the working of dimensionality reduction methods (**K3**).
* **CO3:** Evaluate a solution for open-ended real-world applications with the use of suitable machine learning algorithms (**K6**).

### Laboratory System & Infrastructure Requirements
* **Hardware:** Desktop environments (Recommended Intel i5 processor base, Minimum 16 GB RAM setup).
* **Software Environment:** Open-source Python 3.x stack environment alongside Jupyter Notebook wrappers.
* **Core Libraries utilized:** NumPy, SciPy, Matplotlib, Pandas, and Scikit-Learn.
