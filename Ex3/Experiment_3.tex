\section{Objective}
The goal of this experiment is to build a linear regression model and see how adding different regularization techniques (Lasso, Ridge, and ElasticNet) affects it. I'll also be doing some hyperparameter tuning with cross-validation to find the best alpha values, plotting how the coefficients change, and graphing learning curves to see how the models improve as they get more data.

\section{Problem Statement}
The problem we're trying to solve here is predicting a continuous number—specifically, how much of a loan someone should get based on things like their income, assets, and dependents. Since we're dealing with tabular data to predict a continuous output, this is a classic regression problem. We're using regularization to make sure the model doesn't overfit to the training data.

\section{Exploratory Data Analysis}
I looked at the distributions of the features first. It was pretty obvious that things like applicant income and asset values were highly skewed, which makes sense in the real world since a few people earn way more than average. I ended up finding and dropping about 96 extreme outlier rows so they wouldn't pull the regression line too far off track.

\section{Data Preprocessing}
\begin{itemize}
\item \textbf{Missing Value Handling:} For the missing values, I just plugged in the median for numbers and the most frequent category (mode) for text columns.
\item \textbf{Encoding:} The algorithms need numbers to do math, so I converted all the string categories (like Education or Self-Employed status) into basic numeric codes.
\item \textbf{Feature Scaling:} I standardized all the continuous numerical columns to have a zero mean and unit variance. This step is absolutely necessary because regularization penalizes large weights, so if the features aren't on the same scale, the penalty is applied unfairly.
\item \textbf{Outlier Removal:} As mentioned, removing outliers was key so the distance calculations didn't get distorted.
\end{itemize}

\section{Machine Learning Algorithm}
I tested four different models to see which one handles the data best:
\begin{itemize}
\item \textbf{Standard Linear Regression:} This just draws a line that minimizes the squared error between the predictions and the actual loan amounts. No penalties involved.
\item \textbf{Ridge (L2):} This adds a penalty based on the square of the coefficients. It pulls the weights closer to zero so no single feature dominates. $Cost = RSS + \alpha \sum \beta_i^2$.
\item \textbf{Lasso (L1):} This adds a penalty based on the absolute value of the coefficients. Unlike Ridge, it can actually push some weights exactly to zero, which basically acts like automatic feature selection. $Cost = RSS + \alpha \sum |\beta_i|$.
\item \textbf{ElasticNet (L1+L2):} This is just a mix of both Ridge and Lasso, and you can control the mix with the \texttt{l1\_ratio} parameter.
\end{itemize}

\section{Discussion}
The standard linear regression actually did really well right out of the box, getting an $R^2$ of about 0.87. Adding Ridge and ElasticNet gave almost identical results, which tells me the baseline model wasn't really suffering from severe overfitting to begin with. But the interesting part was Lasso: even though its test score dropped very slightly, it ended up getting the best average score during the 5-fold cross-validation. This implies that dropping a few weak features actually made the model slightly more robust on new, unseen data.

\section{Conclusion}
In the end, this lab was a great way to see how L1 and L2 regularization actually work in practice. The plots really helped visualize the theoretical difference between Ridge (which just shrinks weights) and Lasso (which drops them entirely). The learning curves also confirmed that once we tuned the hyperparameters, the models were stable and did a solid job at predicting the loan amounts.
