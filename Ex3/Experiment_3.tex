\section{Objective}
To implement linear regression using Regularization techniques including L1 (Lasso), L2 (Ridge), and L1+L2 (ElasticNet). The experiment also aims to perform hyperparameter tuning to find appropriate alpha penalization values using Cross-Validation, plot the regularized coefficients versus alpha, and plot learning curves for the regularized models.

\section{Problem Statement}
The problem requires building a robust regression model to predict the continuous \texttt{loan\_amount} variable based on applicant features such as income, assets, and dependents. The input is tabular demographic and financial data, and the output is a continuous predicted loan amount, scaled appropriately. The objective is to apply regularization to prevent overfitting and improve generalization.

\section{Exploratory Data Analysis}
Exploratory analysis was performed to understand feature distributions. Visualizations and statistical summaries highlighted that some applicant features (like income and asset values) had significant skew. A total of 96 extreme outlier rows were identified and dropped before scaling the dataset.

\section{Data Preprocessing}
\begin{itemize}
\item \textbf{Missing Value Handling:} Numerical columns were imputed with their median. Categorical columns (like Education, Self-Employed, Loan\_Status) were imputed using the mode.
\item \textbf{Encoding:} Categorical string columns were encoded into numeric category codes for matrix compatibility.
\item \textbf{Feature Scaling:} All numerical continuous columns, including \texttt{income\_annum}, \texttt{cibil\_score}, and asset values were standardized (zero mean, unit variance) to ensure regularization penalties were applied uniformly across features.
\item \textbf{Outlier Removal:} Extreme outliers were removed to prevent distortion in the Ordinary Least Squares (OLS) distance calculations.
\end{itemize}

\section{Machine Learning Algorithm}
Four variations of Linear Regression were tested:
\begin{itemize}
\item \textbf{Standard Linear Regression:} Fits a linear model minimizing the residual sum of squares between the observed targets and predictions. No regularization penalty.
\item \textbf{Ridge (L2):} Adds an L2 penalty equal to the square of the magnitude of coefficients. Formula: $Cost = RSS + \alpha \sum \beta_i^2$.
\item \textbf{Lasso (L1):} Adds an L1 penalty equal to the absolute value of the magnitude of coefficients. Can yield sparse models where some coefficients become exactly zero. Formula: $Cost = RSS + \alpha \sum |\beta_i|$.
\item \textbf{ElasticNet (L1+L2):} A convex combination of Ridge and Lasso penalties, controlled by an \texttt{l1\_ratio} parameter.
\end{itemize}

\section{Discussion}
The baseline Linear Regression model performed strongly with an $R^2$ of 0.8736. Applying Ridge and ElasticNet regularization yielded nearly identical performance, indicating that the baseline model was not severely overfitting. However, applying Lasso regularization revealed an interesting dynamic: despite a negligible drop in test $R^2$ (to 0.8724), Lasso achieved the highest average Cross-Validation score (0.8580), suggesting that its built-in feature selection slightly improved the model's robustness and generalization capability across unseen data folds.

\section{Conclusion}
The experiment successfully demonstrated the application of L1 and L2 regularization on a continuous regression task. By plotting the coefficients against varying alpha values, the theoretical difference between Ridge (smooth shrinkage) and Lasso (sparse shrinkage) was practically observed. Furthermore, the learning curves confirmed that the optimal hyperparameter configurations lead to stable and generalizable predictive models for determining loan amounts.
