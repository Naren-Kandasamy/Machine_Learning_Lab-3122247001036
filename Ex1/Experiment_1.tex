\section{Exploratory Data Analysis}
During the automated pipeline exploration, basic EDA was implemented using \texttt{Pandas} and \texttt{Matplotlib} to understand the dataset's characteristics. This includes generating dataset overviews (like \texttt{df.head()}), statistical summaries (\texttt{df.describe()}), and checking for missing values (\texttt{df.isnull().sum()}). Visualizations such as histograms and correlation matrices were explored to understand feature distributions and relationships.

\section{Data Preprocessing}
The data preprocessing steps incorporated into the master pipeline included:
\begin{itemize}
\item \textbf{Missing value handling:} Imputation of missing numerical values using the mean or median, and categorical values using the mode.
\item \textbf{Encoding:} Categorical variables were encoded into numerical representations (e.g., Label Encoding or One-Hot Encoding).
\item \textbf{Feature scaling:} Numerical features were standardized or normalized using \texttt{StandardScaler} or \texttt{MinMaxScaler} to ensure uniform scales for distance-based algorithms.
\item \textbf{Train-test split:} Datasets were divided into training, validation, and testing sets using \texttt{train\_test\_split} from \texttt{scikit-learn} (e.g., an 85\%-15\% split).
\item \textbf{Feature selection:} \texttt{SelectKBest} was utilized to isolate the top features for tabular data based on statistical tests.
\end{itemize}
