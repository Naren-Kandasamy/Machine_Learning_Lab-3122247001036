\section{Objective}
The purpose of this lab was to gain practical experience with the standard Python data-science libraries -- Numpy, Pandas, Scipy, Scikit-learn, and Matplotlib -- by applying them to real datasets. This involved practicing array handling, cleaning up messy data, building a basic machine learning pipeline, and producing an exploratory data analysis summary figure.

\section{Problem Statement}
Before any complex machine learning models can be built, a reliable data processing pipeline needs to be in place. This experiment focuses on that groundwork: bringing in datasets of different shapes and sources, dealing with missing values, encoding categorical strings into numeric form, scaling the numerical inputs, and setting up an automated way to generate exploratory visualizations.

\section{Dataset Description}

\section{Exploratory Data Analysis}
Before any preprocessing was carried out, each dataset was examined using Pandas, Matplotlib, and Seaborn to get a sense of its structure and content. A reusable function was written to automatically pick out the most relevant numerical features and lay out exactly 12 subplots on a single page, following the required Times New Roman, 15 pt, bold axis-label format specified for the lab.

\section{Data Preprocessing}
To bring the data into a form suitable for modeling, a preprocessing pipeline was put together consisting of the following steps:
\begin{itemize}
\item \textbf{Handling missing values:} missing entries in numeric columns were filled in using the median, while missing categorical values were filled in using the mode.
\item \textbf{Encoding:} categorical variables were converted to numeric form using simple label encoding.
\item \textbf{Feature scaling:} numerical columns were scaled using \texttt{StandardScaler}.
\item \textbf{Train-test split:} the datasets were split into training and testing sets, in roughly an 80\%-20\% ratio, using Scikit-Learn's \texttt{train\_test\_split}.
\item \textbf{Feature selection:} \texttt{SelectKBest} was used to pick out the features that carry the most useful signal, based on statistical scoring.
\end{itemize}

\section{Discussion}
This lab made it clear why libraries such as Pandas, NumPy, and Scikit-Learn are so widely used in practice. Pandas made handling missing data and restructuring columns considerably easier, requiring very little code for tasks that would otherwise be tedious to write by hand. Scikit-Learn took care of scaling and splitting the data efficiently. Setting up the single-page, 12-subplot EDA layout also showed that Matplotlib output can be formatted programmatically to meet a fairly strict set of presentation requirements.

\section{Conclusion}
The objectives of this lab were met. Practical experience was gained with Numpy, Pandas, Scikit-Learn, and Matplotlib, and a preprocessing pipeline flexible enough to handle a range of different datasets was put together, along with a reusable plotting function that can be customized as needed. Working through each dataset individually also helped build a clearer sense of how to frame a problem correctly before moving on to model training in the experiments that follow.
