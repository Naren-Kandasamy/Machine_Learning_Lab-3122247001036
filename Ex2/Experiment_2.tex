\section{Objective}
To implement and compare the performance of multiple Na\"{i}ve Bayes variations (Gaussian, Multinomial, Bernoulli) against K-Nearest Neighbors (KNN) on the Kaggle Spambase dataset. The experiment evaluates the effect of varying hyperparameter $k$, compares KDTree vs BallTree structures, optimizes KNN using GridSearchCV and RandomizedSearchCV, and validates using 5-Fold Cross Validation.

\section{Problem Statement}
The problem is to accurately classify emails as either "Spam" or "Ham" based on the occurrence and frequency of specific words and characters. The input is a text-based dataset pre-processed into 57 continuous numerical features. The output is a binary prediction ($1$ for Spam, $0$ for Ham).

\section{Data Preprocessing}
The data preprocessing steps for this dataset included:
\begin{itemize}
\item \textbf{Handling Sparsity:} Standard statistical imputation and zero-mean scaling were skipped for the Na\"{i}ve Bayes models to preserve the exact frequency structures of the features.
\item \textbf{Scaling for KNN:} Since distance-based algorithms are highly sensitive to unscaled data, a \texttt{MinMaxScaler} was specifically applied to the training and testing sets before fitting the KNN model.
\item \textbf{Train-test split:} The dataset was split into Training, Validation, and Testing sets using a stratified approach to maintain class ratios.
\end{itemize}

\section{Machine Learning Algorithm}
Two primary types of algorithms were evaluated:

\textbf{1. Na\"{i}ve Bayes (Gaussian, Multinomial, Bernoulli):}
\begin{itemize}
\item \textbf{Working principle:} A probabilistic classifier based on Bayes' theorem, applying a strict "na\"{i}ve" independence assumption between the features.
\item \textbf{Mathematical formulation:} $P(c|x) = \frac{P(x|c)P(c)}{P(x)}$ where $c$ is the class and $x$ is the feature vector.
\end{itemize}

\textbf{2. K-Nearest Neighbors (KNN):}
\begin{itemize}
\item \textbf{Working principle:} An instance-based algorithm that assigns a class based on the majority vote of the $k$ closest training examples.
\item \textbf{Mathematical formulation:} Euclidean distance: $d(p, q) = \sqrt{\sum_{i=1}^{n} (q_i - p_i)^2}$.
\item \textbf{Tree Structures:} KDTree and BallTree structures were used to speed up distance calculations and spatial queries over brute force.
\end{itemize}

\section{Discussion}
Multinomial Na\"{i}ve Bayes proved highly effective among the probabilistic models, achieving 89.58\% test accuracy and a high ROC-AUC of 0.9558. However, after extensive hyperparameter tuning using GridSearchCV (finding $k=7$, weights='distance'), the K-Nearest Neighbors classifier outperformed the Na\"{i}ve Bayes variations, achieving a stable average 5-Fold CV Accuracy of 90.85\%. Furthermore, utilizing the BallTree algorithm proved slightly faster than KDTree for spatial predictions on the 57-dimensional dataset.

\section{Conclusion}
In conclusion, the experiment demonstrated that while probabilistic models like Multinomial Na\"{i}ve Bayes are extremely fast and perform well on text data, distance-based algorithms like K-Nearest Neighbors can achieve superior classification performance (90.85\% Accuracy) after careful hyperparameter tuning and spatial tree optimization.
