\section{Objective}
For this experiment I worked with Naïve Bayes (Gaussian and Multinomial) and K-Nearest Neighbors on the Spambase dataset, mainly to see how a probabilistic classifier stacks up against a distance-based one when the job is telling spam emails from ham.

\section{Problem Statement}
Each email in this dataset is represented as a set of frequencies -- how often certain words and characters show up. Given that, the goal is simply to build something that can look at these frequencies and decide, reasonably reliably, whether a given email is spam.

\section{Data Preprocessing}
KNN works by measuring Euclidean distance, so if one feature happens to have a much larger range than the rest, it ends up dominating that distance calculation whether it deserves to or not. \texttt{StandardScaler} takes care of this by putting all the numerical features on the same footing before they go into the KNN model. Multinomial Naïve Bayes is a bit different -- it needs non-negative values to work correctly, so I left those features in their original, unscaled form for that model. Beyond that, the data was split 70/30 into training and test sets.

\section{Machine Learning Algorithm}
Two models went into this experiment:
\begin{itemize}
    \item \textbf{Naïve Bayes:} built on Bayes' theorem, with the (fairly strong) assumption that all features are independent of one another given the class. I used the multinomial variant since it handles count-style features like word frequencies well.
    \item \textbf{K-Nearest Neighbors (KNN):} doesn't really "learn" a model in the usual sense -- it just looks at the K closest points to a new sample and goes with whichever class is most common among them, using Euclidean distance to decide "closest."
\end{itemize}

\section{Discussion}
KNN was the clear winner in this comparison -- about 90\% accuracy against MNB's 79\%, with a similar gap in F1-score. My guess is this comes down to the independence assumption Naïve Bayes relies on. In an email, word choices aren't independent at all; certain words tend to show up together (think "free," "win," "click" all appearing in the same spam message), and that correlation is exactly what the naïve assumption throws away.

\section{Conclusion}
Working through this lab gave a decent side-by-side look at a probabilistic method and a distance-based one. Once the features were properly scaled, KNN did a solid job separating spam from ham, better than Naïve Bayes managed on the same data.
