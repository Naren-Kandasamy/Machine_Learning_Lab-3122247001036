\section{Objective}
In this experiment, I wanted to see how different versions of the Na\"{i}ve Bayes algorithm (like Gaussian, Multinomial, and Bernoulli) compare against a standard K-Nearest Neighbors (KNN) model. Using the Kaggle Spambase dataset, I also looked into tuning the hyperparameter $k$, comparing how fast KDTree and BallTree structures run, and using Cross Validation to make sure the results are actually reliable.

\section{Problem Statement}
The main goal here is pretty straightforward: figure out if an email is "Spam" or "Ham" based entirely on how often certain words and characters show up in the text. The input is a table of 57 numerical features (word frequencies), and the output is just a simple binary prediction where 1 means it's spam and 0 means it's a normal email.

\section{Data Preprocessing}
Getting the data ready involved a couple of specific steps:
\begin{itemize}
\item \textbf{Handling Sparsity:} Since this is text frequency data, I skipped the usual mean-imputation and zero-mean scaling for the Na\"{i}ve Bayes models. I didn't want to accidentally ruin the exact frequency counts of the words.
\item \textbf{Scaling for KNN:} KNN calculates physical distances between points, so it's super sensitive to unscaled data. I made sure to apply a \texttt{MinMaxScaler} to the training and testing sets before fitting the KNN model.
\item \textbf{Train-test split:} I split the dataset into Training, Validation, and Testing sets. I used a stratified split so that the ratio of spam to ham stayed consistent across all the sets.
\end{itemize}

\section{Machine Learning Algorithm}
I evaluated two main types of algorithms for this task:

\textbf{1. Na\"{i}ve Bayes (Gaussian, Multinomial, Bernoulli):}
\begin{itemize}
\item \textbf{How it works:} It's a probabilistic classifier based on Bayes' theorem. It assumes that every feature is completely independent of the others, which is a bit "na\"{i}ve" for words in an email, but it usually works pretty well anyway.
\item \textbf{Math behind it:} $P(c|x) = \frac{P(x|c)P(c)}{P(x)}$ where $c$ is the class and $x$ is the feature vector.
\end{itemize}

\textbf{2. K-Nearest Neighbors (KNN):}
\begin{itemize}
\item \textbf{How it works:} Instead of building an underlying probability model, it just looks at the $k$ closest data points in the training set and takes a majority vote.
\item \textbf{Math behind it:} It usually uses straight-line Euclidean distance: $d(p, q) = \sqrt{\sum_{i=1}^{n} (q_i - p_i)^2}$.
\item \textbf{Tree Structures:} I used KDTree and BallTree structures to help speed up the math, since calculating the distance to every single point one by one is way too slow.
\end{itemize}

\section{Discussion}
The results were actually pretty interesting. Multinomial Na\"{i}ve Bayes proved to be highly effective, hitting almost 90\% test accuracy and a really high ROC-AUC of 0.9558. But, once I spent some time tuning the KNN classifier using GridSearchCV (which settled on $k=7$ and distance-based weights), KNN actually managed to pull ahead. It got a very stable average accuracy of 90.85\% across the 5-fold cross-validation. Also, between the two tree algorithms I tested, BallTree ended up being slightly faster than KDTree for making predictions on this dataset.

\section{Conclusion}
To wrap things up, the experiment showed that while probabilistic models like Na\"{i}ve Bayes are super fast and great for dealing with text data, you can actually beat them with distance-based algorithms like KNN if you take the time to scale the data and tune the hyperparameters properly. Both models did a great job at figuring out what was spam and what wasn't.
